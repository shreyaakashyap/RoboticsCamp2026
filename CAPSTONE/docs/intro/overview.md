# Introduction

To demonstrate the skills in both circuit building and computer science that I have acquired over an 8 week Robotics Camp, I have created a Capstone Project with the premise being to showcase different facets of robotics in one fully-functioning system. 

Throughout my experience working with digital electronics, I have worked with breadboards and both input and output devices with the completion of 50+ SunFounder Pico 2W projects.

## Page Layout

I have designed this documentation page with the steps used to create an originaal project in mind. I used the CARD, BTP method with CARD (Concept, Analysis, Requirements, and Design) as the planning steps and BTP (Build, Test, and Present) as the execution steps. 

More detailed information can be found throughout this documentation.
