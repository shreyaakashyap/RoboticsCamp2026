# Candidate Ideas

## Practical
- Car sensor, similar to the one infront of modern cars used to assist drivers in maintaining a safe distance between the vehicle and other objects
- Automatic plant waterer where users can set a time for their plant to be supplied with water daily
- A tempertature detector which triggers a small fan when the detected temperature exceeds a certain level
- A security system using an RFID module which displays a secret message only if the right tag interacts with it
- An alarm clock set by the user
- A way to display the power that a batter connected provides

- Manually turning a knob to change the pitch of a sound
